ModuWeb 자동 초기화 예제

1줄 설치

이 페이지는 초기화 JavaScript 코드 없이 script 태그 한 줄로 도구를 삽입하는 예제입니다.


<script src="path/to/dist/webAccTools.js" data-wat-auto></script>

config 파일 없이 인라인 JSON으로 설정할 수도 있습니다.


<script src="path/to/dist/webAccTools.js" data-wat-auto
	data-wat-config='{"branding": {"copyrightUrl": "https://example.com"}}'></script>

본문 예시

접근성 도구 패널에서 글꼴, 색상, 화면 배율, 음성 읽기 등을 조절해 보세요. 이 문단은 도구가 페이지 콘텐츠에 스타일을 적용하는 것을 확인하기 위한 예시 텍스트입니다.
