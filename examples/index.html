ModuWeb — Web Accessibility Tools

웹 접근성 향상을 위한 통합 도구 · 예제 및 사용 가이드

ModuWeb은 웹 접근성을 향상시키기 위한 JavaScript 플러그인입니다. HTML에 스크립트를 추가하고 초기화하는 것만으로 TTS, STT, 화면 확대, 색상 조절 등 다양한 접근성 기능을 웹사이트에 제공할 수 있습니다.

시작 단계

1

라이브러리 추가

  • HTML에 CSS 파일을 포함합니다
  • webAccTools.js 스크립트를 추가합니다
2

설정 파일 준비

  • config.example.json을 config.json으로 복사합니다
  • 서버 엔드포인트 등 필요한 값을 수정합니다
3

인스턴스 생성 및 초기화

  • WAT 클래스로 인스턴스를 생성합니다
  • init() 메서드를 호출합니다
4

기능 활용

  • TTS, STT, 포커스 읽기 등 기능을 사용합니다
  • API를 통해 프로그래밍 방식으로 제어합니다
