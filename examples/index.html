WAT: Web Accessibility Tools

ModuWeb은 웹 접근성 지원 도구입니다. 다양한 사용자의 접근성 요구사항을 충족시키기 위해 설계된 모듈형 플러그인 시스템입니다. 웹사이트 관리자 및 개발자는 최소한의 노력으로 웹 접근성을 개선하고, 웹사이트 사용자에게 향상된 경험을 제공할 수 있습니다.

🎯 시작 단계

1. 라이브러리 추가

  • HTML에 스크립트 파일을 추가합니다
  • CSS 파일을 포함합니다
  • 기본 설정을 확인합니다

2. 인스턴스 생성

  • JavaScript에서 WAT 클래스로 인스턴스를 생성합니다
  • 초기 설정 옵션을 구성합니다
  • 이벤트 리스너를 등록합니다

3. 초기화 실행

  • init() 메서드를 호출하여 WAT를 초기화합니다
  • 기본 기능들이 활성화됩니다
  • 사용자 인터페이스가 표시됩니다

4. 기능 활용

  • TTS, STT, 포커스 읽기 등 다양한 기능을 활용합니다
  • 사용자 설정을 조정합니다
  • 접근성 향상을 확인합니다
