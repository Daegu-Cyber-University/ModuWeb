========================================================
 ModuWeb (웹 접근성 지원 도구) — 배포 패키지
========================================================

■ 처음이신가요?
  → "install-guide.html" 파일을 브라우저로 여세요. (더블클릭)
    코딩 지식 없이 따라 할 수 있는 설치 안내가 들어 있습니다.

■ 바로 동작을 보고 싶으세요?
  → "example.html" 파일을 브라우저로 여세요.
    화면 오른쪽에 접근성 도구가 나타납니다.

--------------------------------------------------------
 가장 빠른 설치 (파일 1개 + 코드 1줄)
--------------------------------------------------------
 1) "webAccTools.standalone.min.js" 파일을 내 웹사이트에 복사
 2) 내 웹페이지 <head> 안에 아래 한 줄을 추가

    <script src="/webAccTools.standalone.min.js" data-wat-auto></script>

 3) 저장 후 새로고침 — 끝!
    (한국어 내장, 인터넷/폐쇄망 상관없이 동작)

--------------------------------------------------------
 이 패키지에 들어 있는 것
--------------------------------------------------------
 webAccTools.standalone.min.js  단일 파일 (이것만으로 설치 가능)
 dist/                          폴더 방식·다국어용 (install-guide 방법 B)
 install-guide.html             일반 사용자 설치 안내 (먼저 여세요)
 example.html                   그대로 열어보는 동작 예제
 README.md                      개발자용 상세 문서 (소스 수정·빌드 방법 포함)

--------------------------------------------------------
 개발자이신가요? (소스를 고쳐서 쓰고 싶을 때)
--------------------------------------------------------
 → "README.md" 의 "개발자 가이드 — 수정하고 다시 배포하기" 절을 보세요.
   요약: 소스는 src/ 에 있고, 고친 뒤 `npm install` → `npm run build`
   로 dist/ 를 다시 만들어 배포합니다.
